# 任务卡：有机形态迷宫 + 新配色（黑墙/白通道/灰障碍/蓝起/红终）

## 目标

参考用户示例图，把当前「直角房间式网格迷宫」改为「手绘有机形态」迷宫，并统一三栏配色：

- **形态**：通道由不规则节点 + 随机生成树连接，沿中心线用可变半径圆盘填充（宽通道、圆角、宽窄变化、节点处有膨大腔室），墙为未填充区域。
- **连通性**：节点间用 Kruskal 生成树保证全连通；额外边按概率成环；起点/终点分别从左右边界接入最近节点，保证起点→终点至少一条路径。
- **障碍**：新增第三类格 `OBSTACLE`（灰色），为通道内的斑块，**阻挡移动**；求解器撞到后按已知障碍推断并规避。
- **颜色**：墙体 `#000000`，可通行区域 `#ffffff`，障碍 `#808080`，起点蓝色，终点红色。
- **三栏**：右=完整地图（新配色 + 蓝/红圆点标注起终点）；中=实时视野（障碍不可见，白色底、灰色仅显示“受阻推断”的障碍）；左=已探索合成图（白色已探索、灰色推断障碍、黑色未探索）。

## 非目标

- 不改变破解方「不知道终点、只朝右边界推进」的策略；不更换 A* 算法。
- 不调整 `view_size`（保持配置中的 10×10）、不改速度控制。
- 不做多迷宫同屏、算法对比、持久化、导出 PNG。
- 不新增第三方依赖（不引入 numpy/Pillow）。

## 未知项

无（形态范围、障碍语义、渲染范围三项已由用户确认）。

## 假设

- 保留 1000×1000 逻辑网格与 1 格=1 像素的完整地图渲染；画布以 CSS 缩放显示，使有机边缘在缩小后平滑。
- 灰色障碍的连通安全用「保护最短路径」实现：生成后先算一条起点→终点最短路径，其邻域内不放置障碍，因此障碍不会切断起终点连通。
- 起点固定在左边界垂直居中，终点固定在右边界垂直居中（沿用现有约定）。

## 候选方案

已在提问阶段收敛，不再展开；实现采用「节点生成树 + 圆盘笔刷填充」。

## 验收

- [ ] `uv run python -c` 以固定 seed（如 42）生成迷宫，输出墙格/障碍格/空白格数量，且起点→终点 BFS 可达（连通性硬性验收）。
- [ ] 网格含三种状态：`WALL=1`、`OBSTACLE=2`、`EMPTY=0`；`is_blocked()` 对墙与障碍均为 True。
- [ ] 连通性验收：8 个种子（42/7/99/123/2024/5/88/77）起点→终点均 BFS 可达。
- [ ] 求解器冒烟：固定种子下 `uv run` 的求解循环能推进且不报错；受阻会记录为灰色障碍格（knownWalls）。
- [ ] 渲染验收：在浏览器打开的验证页中，右栏墙体为黑、通道为白、障碍为灰、起点蓝点、终点红点；中/左栏无残留暗色主题。
- [ ] `py_compile` 全部源码通过，`uv run maze` 能启动窗口。

## 产物路径

- `src/maze/maze.py`（有机形态生成 + OBSTACLE 状态）
- `src/maze/solver.py`（障碍视为阻挡）
- `src/maze/visual.py`（三栏新配色与起终点标注）
- `src/maze/__main__.py`（日志统计障碍数）
- `config.toml`（生成参数：节点间距/抖动、通道半径、环概率、障碍斑块数）
