# 任务卡：八向移动（规划 + 沿墙，禁止切角、√2 代价、前端可切换）

## 目标

把规划/聚类/前沿移动与沿墙模式都扩展到八向，并在界面上可直接切换和观察：

1. **八向移动**
   - 新增 8 邻域（E、SE、S、SW、W、NW、N、NE）。
   - 规划、聚类、前沿入口、Dijkstra 扩展均使用 8 向。
   - **禁止切角**：对角移动要求目标格 + 两个相邻正交格都可通行；规划时三者都必须已知可通行，实际移动时用真实地图再次校验。
   - 对角代价 = 水平方向基础代价 × `diagonal_factor`（默认 1.414）。
2. **八向右手沿墙**
   - 方向按顺时针编号（0=E … 7=NE），相对转向按顺时针步数表示。
   - 8 向右手转向顺序：**+1（45°右）→ +2（90°右）→ 0（直）→ -1（45°左）→ -2（90°左）→ +3（135°右）→ -3（135°左）→ +4（掉头）**。
   - 说明：45° 优先于 90°，否则在走廊里会优先贴墙直行，几乎用不到对角移动。
   - 沿墙同样禁止切角；撞到未知障碍时标记后换下一个转向。
   - 打转检测：记录 `(位置, 朝向)`，重复或八个方向都不可行时切到规划模式。
3. **前端 4/8 向切换**
   - 顶栏新增「移动」选择框：`4 向` / `8 向`；该开关**同时作用于规划与沿墙**。
   - `Api.get_move_mode()` / `Api.set_move_mode(mode)`；切换后清空当前路径、重置沿墙朝向/状态，下一次决策生效。
   - 状态栏显示当前移动模式。
4. **斜移轨迹可视化**
   - 右栏轨迹在相邻访问点之间画连线（含对角），避免斜移看起来像断开的方块；重开/切换模式时清空。
5. **增量观测**
   - 正交移动仍只观测新进入的一条边；对角移动同时观测新进入的一列 + 一行（去重）。
6. **配置**
   - `allow_diagonal`（默认 true）与 `diagonal_factor`（默认 1.414）；关闭即整体回到四向（规划 + 沿墙）。

## 非目标

- 不改迷宫生成、配色、视野滑块。
- 不改策略切换/重开协议。
