# 任务卡：迷宫生成 + A* 破解 + pywebview 可视化

## 目标

用 Python 实现一个迷宫生成与破解演示：随机生成 w×h（1000×1000）迷宫，起点在左、终点在右，可行动区最小 1×1、最大 (w/25)×(h/25)，道路上随机生成障碍；破解方视距 10×10，障碍对其不可见（10×10 内也不可见），靠移动受阻反馈自行推断障碍位置并用 A* 寻路；用 pywebview 三栏可视化（右=完整地图含障碍，中=10×10 实时探索图，左=已探索合成图），自动演示+可调速。

## 非目标

- 不做连通性保证（随机障碍不保证必然连通；若起点终点被隔断，演示仍进行并如实反映受阻）。
- 不做多迷宫同屏、不做寻路算法对比、不做持久化存储。
- 不实现真实感知传感器，只用「移动受阻」这一布尔反馈模拟探测。

## 未知项

已确认：障碍=随机障碍；破解方不知道终点；运行=自动演示+可调速。

## 假设

- 配置集中在一个配置文件（如 `config.yaml` / `config.json` / `config.toml`），便于后续改 w/h、障碍密度、视距、速度等。
- 随机障碍以「块」为单位：每个障碍块面积在 1×1 到 (w/25)×(h/25) 之间随机，块在可行区域内随机放置，不覆盖起点与终点。
- 起点固定在左边界（如 x=0，y 居中），终点固定在右边界（x=w-1，y 居中）。
- 破解方初始不知道终点，也不知道任何障碍；只知道自己当前位置与「移动是否受阻」。
