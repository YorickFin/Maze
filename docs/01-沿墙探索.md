# 沿墙探索（右手法则）

## 一句话概括

贴着右侧墙面走：右边有路就右转，没路就直行，走不动再左转或掉头。它不做任何全局规划，也不需要记忆整张地图，属于典型的**局部反应式**探索。

在本项目里，沿墙是可选策略之一（前端策略下拉的「沿墙」），默认策略是聚类信息增益。

---

## 1. 前提与感知

- 视野边长默认 25×25：视野内的墙与通道都可见，只有灰色障碍不可见。
- 相邻格一定落在历史视野内，因此沿墙只用认知网格 `known` 判断即可，不需要额外的探测。
- 不知道地图尺寸、也不知道终点坐标；红点进入视野后才获得终点，并立即转为直达规划。

代码位置：`_observe()` 见 `src/maze/solver.py:201`，认知状态常量 `KNOWN_EMPTY / KNOWN_WALL / KNOWN_OBSTACLE`。

---

## 2. 四向规则

`src/maze/solver.py:39`

```python
WALL_DIRS4 = ((1, 0), (0, 1), (-1, 0), (0, -1))  # E, S, W, N
WALL_TURNS4 = (1, 0, 3, 2)                        # 右90 → 直 → 左90 → 掉头
```

- 每成功走一步后，尝试顺序从「右 90°」重新开始。
- 若尝试的格是已知墙/已知障碍，直接跳过，不计步。
- 若尝试的是未知格但实际撞上（灰色障碍），记为已知障碍，这一步算一次受阻，下一步从下一个方向继续。
- 每次成功后把 `(位置, 朝向)` 记入 `wall_states`；一旦出现重复状态，视为打转，`wall_failed=True` 并**永久**切到规划模式，避免两种模式来回抖动。

在本项目的 20 个种子上，四向沿墙从未触发打转兜底（`wall_failed=False`）。

---

## 3. 八向规则（改造后）

### 3.1 旧规则为什么失败

旧顺序是 `(1, 2, 0, 7, 6, 3, 5, 4)`：45°右优先，而且不是单调扫描（135°右 被排在 90°左 之后）。

- 45° 斜步会沿着弧线「蹭」离墙面，在腔室里绕小圈；
- 实测约 40~60 步就出现 `(位置, 朝向)` 重复，触发兜底；
- 于是八向「沿墙」实际上只有不到 1% 的步数在沿墙，其余全是前沿规划。

### 3.2 新规则：贴墙优先 + 开阔直行

`src/maze/solver.py:44`

```python
WALL_TURNS8 = (2, 1, 0, 7, 6, 5, 3, 4)   # 90°右 → 45°右 → 直 → 45°左 → 90°左 → 135°左 → 掉头
WALL_DRIFT8 = (0, 1, 7, 2, 6, 5, 3, 4)   # 无墙可贴时：直行 → 斜前 → 直角 → 掉头
```

`_wall_step8()`（`src/maze/solver.py:673`）分两轮扫描：

1. **贴墙轮**：按 `WALL_TURNS8` 顺时针扫描，候选必须满足「移动后右侧半平面（45°/90°/135°）仍有墙」，由 `_keeps_wall_on_right()` 判定。这样 90° 右转优先，保证走路时右墙始终在右侧。
2. **兜底轮**：附近没有墙可贴时，按 `WALL_DRIFT8` 取第一个可行方向。直行优先，避免在宽通道/腔室里原地绕圈。

### 3.3 对角移动的取舍

- 严格「禁止切角」（对角要求两个正交邻格都可通行）时，贴墙状态下 2×2 邻域必然包含墙，**斜步在几何上永远不可用**（实测斜步数为 0，八向沿墙退化成四向）。
- 因此八向沿墙改为「允许擦单侧墙角，禁止穿过两侧都是墙的对角缝隙」：候选对角步的两侧若都有墙直接跳过。
- 规划模式仍保持严格禁止切角，两者规则分离。

实测该规则下沿墙路径中「两侧都是墙」的对角缝出现 0 次，不存在穿墙作弊。

---

## 4. 复杂度与开销

- 每步只做常数次候选检查（最多 16 次），不涉及任何搜索。
- 单步成本约 0.02ms 量级；20 个种子全部跑完总耗时约 3.1s（四向，约 0.16s/种子）。
- 内存只随已探索格数增长（`known` / `explored` / `visited`）。

---

## 6. 优点

- 单步成本极低，可视化直观，行为完全可解释。
- 在完美迷宫（无环）中是可完备的：贴着同一侧墙一定能走遍可通行区域。
- 不需要全局搜索，也不依赖视野大小（视野 10 与 25 结果相同）。
- 八向贴墙后步数比四向少约 29%，路径几何长度也更短。

## 7. 缺点

- **没有目标导向**：路径长度近似于所贴墙体的周长，倍率通常 3~7×，与最优路径无关。
- 存在环路时可能绕圈，检测到状态重复后只能交给规划模式。
- 通道很宽（半径 13~40 格）时，「贴墙」语义被弱化，容易脱离墙面进入开阔区。
- 灰色障碍不可见，贴墙时撞上才记录，会消耗步数。

## 8. 改进与经验

- 换左手只需改 `WALL_TURNS4` / `WALL_TURNS8` 的相对顺序；台账 S-20261107-016 实测左手平均 4.47×，略优于右手 4.67×。
- 在沿墙之上叠加「向右捷径」是负收益：会打断整体路线、频繁重规划（台账 S-20261107-015 实测倍率反而升到 7~26×）。
- 想提升路径质量应改用聚类信息增益，而不是继续调沿墙规则。
